🧪 Расширенная таблица Менделеева

Интерактивная периодическая таблица химических элементов с подробными характеристиками, калькуляторами и тренажёром для решения школьных задач по химии.

🌐 Демо

После публикации через GitHub Pages сайт будет доступен по адресу:

https://ТВОЙ-ЛОГИН.github.io/periodic-table/

✨ Возможности
🔬 Интерактивная таблица
Все 118 химических элементов.
Поиск по названию, символу и порядковому номеру.
Фильтрация по периодам, группам и типам элементов.
Выделение элементов школьной программы.
Подробные карточки каждого элемента.
Информация о строении атома, валентности и степенях окисления.
Физические и химические свойства элементов.
🧮 Химические калькуляторы
Расчёт молярной массы вещества.
Расчёт массовой доли элемента.
Расчёт количества вещества.
Расчёт числа частиц.
📚 Тренажёр
Генерация случайных задач.
Проверка правильности ответов.
Просмотр подробных решений.
Практика основных школьных тем по химии.
🎨 Дополнительные функции
Светлая и тёмная темы оформления.
Сравнение до трёх химических элементов.
Адаптация для мобильных устройств.
Работа непосредственно в браузере.
🚀 Запуск проекта

Проект не требует установки дополнительных библиотек или серверной части.

Скачайте репозиторий.
Откройте файл index.html в браузере.
🌍 Публикация на GitHub Pages
Откройте Settings репозитория.
Перейдите в раздел Pages.
В Source выберите Deploy from a branch.
Выберите ветку main.
Выберите папку / (root).
Нажмите Save.

После публикации сайт станет доступен по адресу GitHub Pages.
